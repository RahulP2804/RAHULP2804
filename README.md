## 🚀 Featured Enterprise Projects

### 📁 [enterprise-rag-platform](https://github.com/RAHULP2804/doc-intelligence-api-enterprise-rag-platform)
A production-ready, fully multi-tenant document intelligence platform. Users upload raw complex PDFs, which are asynchronously chunked, embedded via GCP Vertex AI, and indexed inside isolated, dedicated database schemas per tenant to ensure zero cross-data leakage. 
* **Key Tech:** Java 21, Spring Boot, pgvector, Redis, GCP Vertex AI with an automated runtime fallback to OpenAI.

### 📁 [spring-ai-gateway](https://github.com/RAHULP2804/spring-ai-gateway)
A high-performance Spring Boot 3 service that routes LLM requests to OpenAI, Anthropic Claude, and Google Gemini behind a single, provider-agnostic REST endpoint. Designed to prevent vendor lock-in, it ships with Redis-backed API key rotation, per-IP rate limiting, structured error responses, and full Micrometer/Prometheus observability.
* **Key Tech:** Java 21, Spring Boot 3, Spring AI, Redis (Sliding Window/INCR), Docker.
